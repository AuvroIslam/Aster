# Screenshots

Ten captures of the running prototype, for slides. Every one is a real
interaction against the live app — nothing is mocked, staged or composited.
All are 3200×2000 (2× for a 1600×1000 viewport), so they stay crisp projected.

| # | File | What it proves |
|---|---|---|
| 01 | `01-landing-hero.png` | What Aster is, in one screen: a visual lesson on one side, the same lesson as audio on the other |
| 02 | `02-ready-to-play.png` | Three lessons already described. A judge can start in one click — no key, no upload, no wait |
| 03 | `03-lesson-surface.png` | The lesson surface: full-width player, transport, speech controls, description list |
| 04 | `04-description-timeline.png` | **25 moments examined · 12 described.** Aster chose to stay quiet at the other 13 — the product's core judgement, visible as a number |
| 05 | `05-speaking-caption.png` | An extended description holding the video, revealed sentence by sentence as it is spoken (*1 of 3*), never overlapping the instructor |
| 06 | `06-ask-the-tutor.png` | Ask about the exact frame on screen — eight one-key presets, or speak the question |
| 07 | `07-practice-question.png` | *"What is the fundamental difference between a persistent and a non-persistent HTTP connection?"* — a real tutor question drawn from the whole lesson, answered out loud |
| 08 | `08-voice-search.png` | Spoken search: press W, speak, and the results are read back. Enter loads the one being announced — a lesson found with two keys and no sight |
| 09 | `09-study-library.png` | Notes and PDFs, with a 102-page document already prepared |
| 10 | `10-study-page-explained.png` | The strongest single frame: a real diagram-heavy slide rendered, with Aster's explanation of it underneath |

## Suggested order for a deck

**The problem** → 01. **It works instantly** → 02. **The core idea** → 04 then 05
(the number, then the moment). **It answers back** → 06, 07. **Without sight at
all** → 08. **Beyond video** → 09, 10.

If you only have room for three: **04, 05, 10**. Those carry the judgement, the
moment, and the reach beyond YouTube.
